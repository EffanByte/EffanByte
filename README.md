# 🚀 Featured Work

## 🧠 AI / Machine Learning

### Adaptive AI Framework
**Python · C# · PPO · MultiGAIL · Unity ML-Agents**

Adaptive agent framework combining reinforcement learning and imitation
learning with style-conditioned behavior and runtime opponent modelling.

The project includes demonstration-data processing, per-style critic training,
and integration of learned behavior into a real-time combat environment.

[Repository](https://github.com/Sunbro26/FYP)

---

### TokenFlow
**TypeScript · React · NLP · Gemini API**

Interactive visualizer for **BPE, WordPiece, and Unigram tokenization**,
including greedy subword matching, tokenization lattices, and Viterbi decoding.

Also integrates AI-generated explanations of tokenization behavior.

[Repository](https://github.com/EffanByte/Tokenizer-Visualization)

---

### Visual Book Search Engine
**Python · TensorFlow · OpenCV · Pinecone · Flask**

Image-similarity search pipeline using DELF feature extraction and vector
embeddings to retrieve visually similar book covers from uploaded images.
